# 🍕 Forno & Brasa — Pizzaria

Projeto de desenvolvimento Front-end de um site para uma pizzaria fictícia, criado com o objetivo de apresentar um cardápio digital moderno, intuitivo e responsivo.

## 📌 Sobre o projeto

O **Forno & Brasa** é um site desenvolvido para representar a presença digital de uma pizzaria, oferecendo aos visitantes uma experiência visual agradável para conhecer os produtos, visualizar os sabores disponíveis e conhecer um pouco mais sobre a empresa.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com foco na estruturação das páginas, estilização dos elementos e interatividade da interface.

## 🚀 Tecnologias utilizadas

- HTML5 — Estruturação do conteúdo.
- CSS3 — Estilização e responsividade.
- JavaScript — Interatividade e funcionalidades da interface.
- Visual Studio Code — Ambiente de desenvolvimento.

## ✨ Funcionalidades e seções

- Página inicial com apresentação da pizzaria.
- Cardápio com diferentes sabores de pizzas.
- Seção de bebidas e drinks.
- Exibição de preços e produtos.
- Seção institucional sobre a empresa.
- Informações de contato e endereço.
- Menu de navegação adaptado para dispositivos móveis.
- Layout responsivo para diferentes tamanhos de tela.

## 🎨 Interface

O projeto utiliza uma identidade visual com tons escuros, detalhes em amarelo e elementos em tons de bege, buscando transmitir uma aparência moderna e aconchegante.

## 🔧 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server.
